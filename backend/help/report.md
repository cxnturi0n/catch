# Report

Generating and sharing client reports

Generate your weekly client report in seconds instead of hours.

## How to use it
1. Select the workspace you want to report on.
2. Click Generate Report and let Catch pull the week’s data together.
3. Review the output, then share it via email or Telegram.

## Report sections explained
- **Executive Summary**, A one-paragraph overview written for busy founders.
- **Community Growth**, Member and message metrics for the period, pulled live from connected platforms.
- **Moderator Activity**, What each moderator did, from the points/compensation engine.
- **Shift Coverage**, Optional toggle, flags high-traffic hours with no moderator on shift.
- **KOL Activity**, Ambassador highlights and campaign notes.
- **Payments & Tasks**, Salary log and team productivity across the reporting window.

## Pro tips
- Send reports every Monday morning, consistency builds client trust.
- Turn on the Shift Coverage analysis to show clients where you need more hands.
- Save reports to History for reference during renewal conversations.
